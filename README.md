# Ledger — Personal Finance Dashboard

A modern personal finance dashboard built with **React** and **Vite**. The application helps users track income and expenses, visualize spending patterns, and manage monthly budgets through a clean, responsive interface. All data is stored locally using the browser's Local Storage.

## 🚀 Live Demo

https://finsight-personal-finance-dashboard-six.vercel.app

## 📂 GitHub Repository

https://github.com/lokeshkommaraju06/finsight-personal-finance-dashboard

---

## ✨ Features

### 📊 Dashboard
- Financial summary cards
- Expense by category chart
- Income vs Expense chart
- Recent transactions
- Quick statistics
- Responsive design

### 💳 Transactions
- Add transactions
- Edit transactions
- Delete transactions
- Search transactions
- Filter by transaction type
- Local Storage persistence

### 💰 Budget Management
- Create monthly budgets by category
- Track spending against budgets
- Remaining budget calculation
- Budget progress visualization
- Budget exceeded alerts
- Budget summary cards

### 📈 Financial Reports
- Multi-period filtering (All Time, This Month, Last Month, Last 3 Months, This Year, Custom Date Range)
- Cash flow trend visualization (Monthly Income vs Expenses)
- Expense category distribution chart
- Budget vs. Actual spending comparison chart
- Detailed category breakdown table with status indicators
- Top 5 ranked expense transactions
- Automated financial health insights & spending tips
- Export report summary and filtered transactions to CSV
- Print / Save as PDF capability

### ⚙️ Settings & Data Management
- User profile personalization (Name & Email)
- Multi-currency support (USD $, INR ₹, EUR €, GBP £, CAD CA$, AUD A$, JPY ¥, SGD S$, AED) with prefix/suffix formatting
- Configurable date formatting (MMM DD, YYYY, DD/MM/YYYY, YYYY-MM-DD)
- Budget alert warning threshold slider (50% - 100%)
- Default transaction type and category
- Complete application backup (JSON export & import)
- CSV exports for transactions and budgets
- One-click sample demo data restore
- Danger zone operations (Clear transactions, Clear budgets, Factory reset)

npm run dev
